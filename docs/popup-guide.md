# Управление сайтом и ресурсами

Нажмите значок Unroute, находясь на обычной веб-странице. В поле **Подключение сайта** доступны:

- **Автоматически — по PAC**: решение принимает выбранный PAC.
- **Без прокси**: прямое соединение для сайта.
- **Прокси: название**: выбранный именованный профиль.

Недоступный назначенный профиль отображается как недоступный, а не подменяется первым в списке. Бейдж показывает выбранную политику и не является гарантией успешного соединения.

## Ресурсы сайта

Сайт может загружать изображения, скрипты и другие данные с дополнительных доменов. Раскройте список найденных ресурсов, чтобы увидеть их маршрут и при необходимости задать отдельное правило.

**Автоматически** означает применение обычной политики, а не ручное закрепление показанного прокси. Явный выбор профиля или прямого подключения создаёт ручное исключение. Действие **Убрать исключение** возвращает ресурс под действующие правила; более общее ручное правило при этом может продолжить действовать.

Выбор **Как у сайта / Без прокси** относится к автоматическим ресурсам. Уже созданные ручные исключения сохраняются. Назначения ресурсов видны в настройках и могут влиять на тот же домен при посещении других сайтов.

## Различия браузеров

- **Chromium:** обнаруженные домены ресурсов записываются в общие правила. Первый запрос к ещё неизвестному домену может пройти по PAC; назначения действуют и вне исходной вкладки.
- **Firefox:** при настроенном собственном прокси маршрут сайта применяется к запросам его вкладки, без добавления ресурсов в постоянные списки.

Правило домена не различает основной документ и ресурс на том же хосте. Список показывает обнаруженные домены, а не обещает охват любого сетевого запроса.

## После изменения

Перезагрузите сайт кнопкой в окне расширения или обычной командой браузера. Сохранение правила не переключает уже открытые соединения задним числом. При ошибке применения настройки могут быть сохранены, но ещё не применены: повторите попытку после устранения причины.

В приватных окнах и на служебных страницах часть действий ограничена. Firefox должен получить отдельное разрешение на работу в приватных окнах для управления общими прокси-настройками.

Полное управление находится в настройках: [профили прокси](proxy-guide.md), [листы доменов](domain-lists.md), журнал и история. История хранит последние пять операций; у очень больших изменений доступна только сводка без отмены. Очистка истории не удаляет действующие правила.
